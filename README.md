# Piston Pulse — GitHub Pages Demo

This repository root is the live demo source for the Piston Pulse website.

## Current deployment file

- `index.html` — current website build

The site is intentionally kept as a simple static HTML deployment so refinements can be tested by replacing **only `index.html`** and committing the change.

## Refinement workflow

1. Receive/refine the next HTML build.
2. Replace `index.html` with the new build.
3. Commit the change to `main`.
4. GitHub Pages automatically redeploys.
5. Test the live URL on desktop, Android, iPhone/iPad and different browsers.

Do not rename the active file: GitHub Pages expects `index.html` at the top level of the publishing source.
